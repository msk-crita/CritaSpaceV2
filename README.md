# CritaSpace

CritaSpace is a Progressive Web Application (PWA) for shared-workspace boardroom booking. It enables multiple companies within one workspace to reserve and manage shared boardrooms without overlapping bookings.

## Project Structure

```text
CritaSpaceV2/
├── backend/
│   ├── src/
│   ├── .env.example
│   ├── package.json
│   └── tsconfig.json
├── frontend/              
├── .gitignore
└── README.md
```

## Technology Stack

### Backend
- Node.js
- Express.js
- TypeScript
- Firebase Authentication
- Firebase Admin SDK
- Cloud Firestore

### Frontend 
- React
- TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Progressive Web App (PWA)

## Core Capabilities

- Multi-company workspace management
- Shared boardroom management
- Availability and booking management
- Booking overlap prevention
- Booking rescheduling and cancellation
- Booking negotiation and early-release requests
- Recurring bookings
- Boardroom maintenance and availability blocking
- Audit logs and booking history
- Role-based access control
- Dashboard and workspace overview
